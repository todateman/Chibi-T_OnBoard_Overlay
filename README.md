# Chibi-T_OnBoard_Overlay

Honda エコマイレッジチャレンジ用の車載動画テレメトリ・オーバーレイ生成ツール。  
<https://github.com/todateman/Chibi-T_Furoshiki_Logger> の CSV を読み込み、速度・回転数(エンジン ON / COAST)・燃費・ラップタイム・方位・コース図・標高・燃圧などを車載カメラ映像に重ねる。

![preview](docs/preview.png)

## 特徴

- **パルス&グライド向け表示**: 回転数から ENGINE ON / COAST を判定し、コース図と速度グラフ上でエンジン ON 区間をオレンジで表示(コース図は走行中の周の分だけ。`on_segments_scope = "all"` で全周を重ねる)
- **燃費・積算燃料・走行距離**: 距離が短い間の不安定な燃費値は `---` で非表示
- **ラップタイム**: `ラップ数` 列の切り替わりから現在周・前周タイムを算出。最初の周は `走行時間` が動き出した時刻(走行開始)から数える
- **方位**: GPS 座標の移動ベクトルから算出(低速時は直前値を保持)
- **標高・燃圧グラフ**: 標高は出力区間全体のプロファイル、燃圧は直近 60 秒をスクロール表示(エンジン ON 帯付き)
- **10 Hz / 1 Hz ログ対応**: 現行の 10 Hz フォーマットと旧 1 Hz フォーマットの列名を自動判別。センサ更新の間に同じ値が続く部分は間引いてから動画フレームレートへ線形補間
- **ドラレコ焼き込み表示のマスク**: VSYSTO F9 の日時・速度表示を `f9_mask` プリセットの帯で隠す
- **3 つの出力モード**: 静止画プレビュー / 動画へ直接合成 / 透過 ProRes 4444(編集ソフトで重ねる用)
- **分割動画の連結**: ドラレコの 5 分ごとのファイルを、複数ファイルやフォルダの指定でファイル名順に連結して 1 本として扱う。連結だけの書き出しもできる
- **自動同期**: VSYSTO F9 の焼き込み日時を OCR してログと同期(`--sync auto`)。編集のつなぎ目や録画の欠けで時刻が飛んでも、区間ごとに合わせる
- **レイアウトプリセット**: 配置・配色・ゲージ上限などを `presets/*.toml` に分離。`--preset` で切り替え
- **GUI エディタ**: ブラウザでウィジェットをドラッグ・リサイズし、プロパティを編集して保存(`ecorun-gui`)。プレビューは本番と同じ描画
- **AI エージェント向け**: JSON Schema・`ecorun-layout validate / lint`(`--json`)・`--debug-boxes` で、テキスト編集だけでレイアウトを変更・検証できる

## 必要なもの

- Python 3.11 以上([uv](https://docs.astral.sh/uv/) 推奨)
- ffmpeg / ffprobe(PATH が通っていること)
- 日本語フォント(Windows・macOS・Linux の標準的なものは自動検出。見つからない場合は `--font` で指定)
- Tesseract(自動同期を使うときだけ。macOS は `brew install tesseract`、Ubuntu は `apt install tesseract-ocr`)

```bash
uv sync                          # 依存のインストール(.venv を作る)
# または
pip install -r requirements.txt
```

以下のコマンドは `uv run ecorun-overlay ...` の形で書く。`python ecorun_overlay.py ...` でも同じように動く。

## 使い方

### 1. 静止画でレイアウトを確認

```bash
uv run ecorun-overlay LOG0650.CSV --preview 150 -o preview.png
uv run ecorun-overlay LOG0650.CSV --preset minimal --preview 150 --debug-boxes -o preview.png
```

`--preview` はログ開始からの秒数。グレー背景に 1 フレーム描画する。`--debug-boxes` を付けると各ウィジェットの枠と id、配置禁止帯を重ねて描く。

### 2. 車載動画に直接合成

```bash
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9_0001.mp4 --sync 15:10:30 -o out.mp4
```

- 出力は H.264。音声はコピーされる
- エンコーダは macOS ならハードウェアの VideoToolbox、それ以外は x264(`--encoder` で切替、x264 の画質は `--crf`、既定 18)
- 描画は既定で 4 プロセス並列(`--jobs`)。Apple M5 で 1080p 25 fps の 30 分の動画が約 4 分で書き出せる
- オーバーレイは 1920×1080 基準で描画し、動画の解像度へ自動スケール
- フレームレートと長さは動画から自動取得

#### 分割された動画をまとめて合成する

VSYSTO F9 はドライブレコーダーなので 5 分ごとにファイルが分かれる。`--video` に複数ファイルかフォルダを渡すと、連結して 1 本の動画として扱う(中間ファイルは作らない)。

```bash
# フォルダ直下の動画をファイル名順に連結
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/ --sync 15:10:30 -o out.mp4
# ファイルを並べる(シェルの glob も可)。この場合は指定した順に連結
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/*.MP4 --sync 15:10:30 -o out.mp4
```

- `--sync` は連結後の 0 秒目(先頭ファイルの 0 秒目)に対応するログ時刻
- 解像度・フレームレートが揃っていないファイルは連結できない(エラーになる)
- `--video` は残りの引数をすべて動画として受け取るので、CSV は `--video` より前に書く
- 連結は再生時間をつなぐだけなので、ファイルの境目で録画が欠けていると、それ以降の同期がずれる。長い区間を書き出す前に、後ろのファイルの位置でも `--preview` や GUI で同期を確かめる

#### 書き出す区間を指定する

動画の前後にログが記録されていない部分があるときは、`--start` / `--end` で書き出す区間を絞る。位置は動画(連結時は連結後)の再生位置で、秒(`95.5`)か `[H:]MM:SS[.f]`(`1:35`、`0:21:40.5`)で書く。動画プレイヤーに表示される位置をそのまま使える。

```bash
# 動画の 1:35〜21:40 だけを書き出す
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/ --sync 15:10:30 --start 1:35 --end 21:40 -o out.mp4
# 1:35 から 10 分間
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/ --sync 15:10:30 --start 1:35 --duration 600 -o out.mp4
```

- `--sync` は区間を指定しても動画の 0 秒目に対応するログ時刻のまま(区間の先頭ではない)
- 省略すると動画全体。`--end` が動画の長さを超えるときは動画の末尾までに切り詰める
- `--end` と `--duration` は同時に指定できない
- 音声も同じ区間で切り出される
- 速度グラフなど区間全体を描くウィジェットは、書き出す区間を全体として描く(`--preview` に `--start` / `--end` を付けると同じ見た目を確認できる)

#### 連結だけする

```bash
uv run ecorun-overlay --concat-only --video F9/ -o joined.mp4
```

オーバーレイなし・再エンコードなし(無劣化)で連結した動画を書き出す。CSV は不要。編集ソフトで透過オーバーレイ(下記)と重ねるときなどに使う。

### 3. 透過オーバーレイだけを書き出す

```bash
uv run ecorun-overlay LOG0650.CSV --sync 15:10:30 --duration 1300 -o overlay.mov
```

ProRes 4444(アルファ付き)を出力する。DaVinci Resolve や Premiere で映像の上に重ねて使う。`--start` / `--end` も使える(出力の 0 秒目は `--sync` から `--start` 秒後のログ時刻)。

### オプション一覧

| オプション | 説明 |
| --- | --- |
| `csv` | ロガーの CSV ファイル(`--concat-only` のときは不要) |
| `-o`, `--output` | 出力先。`.png`(プレビュー)/ `.mp4`(合成)/ `.mov`(透過) |
| `-p`, `--preset` | レイアウトプリセット名(`presets/NAME.toml`)または `.toml` のパス。既定 `default` |
| `--video` | 合成する車載動画。複数ファイル・フォルダを指定すると連結して 1 本として扱う |
| `--concat-only` | `--video` を連結しただけの動画を書き出す(オーバーレイなし・再エンコードなし) |
| `--sync` | 動画(連結時は先頭ファイル)の 0 秒目に対応するログ時刻(`HH:MM:SS[.f]`)、またはログ開始からの秒。`auto` で焼き込み日時を OCR して自動同期、`.json` なら `ecorun-sync` の結果を使う |
| `--offset` | 同期の微調整 [秒]。正の値で表示が先に進む(自動同期では全区間に足す) |
| `--sync-step` | 自動同期で焼き込みを読む間隔 [秒](既定 10) |
| `--osd-box` | 自動同期で読む焼き込み日時の枠 `X,Y,W,H`(canvas 1920×1080 基準。既定は VSYSTO F9 の位置) |
| `--start` | 書き出し開始位置。動画(連結時は連結後)の再生位置を秒か `[H:]MM:SS[.f]` で。既定 0 |
| `--end` | 書き出し終了位置(`--start` と同じ書式)。省略時は動画の末尾、またはログ末尾まで |
| `--duration` | 出力する長さ [秒]。`--start` からの長さ(`--end` と併用不可) |
| `--preview` | ログ開始からの秒を指定して静止画 1 枚を出力 |
| `--debug-boxes` | ウィジェットの枠と id、配置禁止帯を描く |
| `--fps` | 透過出力時のフレームレート(既定 30。`--video` 指定時は動画に合わせる) |
| `--font` | 日本語フォント(`.ttf` / `.ttc`)のパス。プリセットの `theme.font` より優先 |
| `--crf` | x264 の画質(既定 18、小さいほど高画質) |
| `--encoder` | H.264 のエンコーダ。`auto`(既定。macOS なら `videotoolbox`、それ以外は `x264`)/ `x264` / `videotoolbox` |
| `--x264-preset` | x264 の速さと圧縮率(既定 `medium`。`veryfast` で約 2 倍速) |
| `--jobs` | 描画のプロセス数(既定はコア数の半分、最大 4)。`1` で並列にしない |
| `--mask-osd` | (非推奨)`--preset f9_mask` と同じ |

## 動画とログの同期

### 自動同期(焼き込み日時の OCR)

VSYSTO F9 は GPS と同期した日時を右下に焼き込んでいる。これを Tesseract で読み、動画の各位置がログの何秒目かを求める。

```bash
# その場で OCR して書き出す
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/ --sync auto -o out.mp4

# OCR だけして結果を保存し、あとで使う(長い動画で何度も書き出すとき)
uv run ecorun-sync F9/ --csv LOG0650.CSV -o sync.json
uv run ecorun-overlay LOG0650.CSV --preset f9_mask --video F9/ --sync sync.json -o out.mp4
```

`ecorun-sync` は次のような表を出す。

```text
区間  動画位置 [s]            焼き込み時刻(区間の先頭)   ログ秒
   1       0.00 –     60.06    2023-06-10 10:36:30.76      390.76
   2      60.06 –     73.34    2023-06-10 10:45:21.71      921.71
   3      73.34 –    130.13    2023-06-10 11:03:05.18     1985.18
```

- 動画を 10 秒ごと(`--sync-step`)と各ファイルの先頭・末尾付近で読み、時刻が飛んでいる所で区間を分ける。区間の境目は 1 フレーム単位、各区間の時刻は秒の表示が切り替わるフレームから 1 フレーム程度の精度で求める
- 区間が分かれるのは、編集でつないだ動画や、分割ファイルの境目で録画が欠けているとき。区間ごとに同期するので、途中で時刻が飛んでもずれない。2 秒未満の飛びは区別できない
- 焼き込み時刻がログの範囲に入らない区間は警告する。どの区間もログと重ならなければエラー(差がちょうど何時間かなら、カメラの時計のタイムゾーン設定を疑う)
- 読めない場合は `ecorun-sync F9/ --save-crop crop.png` で切り出し位置と 2 値化の結果を確認し、必要なら `--osd-box` で枠を指定する
- 処理時間の目安: 4 本・計 4.5 分の動画で約 17 秒(Apple Silicon Mac)

> カメラの時計が正しく設定されていないと、焼き込み時刻はログと一致しない(GPS 同期が有効か、日付が合っているかを確認する)。ずれが一定なら `--offset` で補正できる。

### 手動で合わせる

1. 動画で発進の瞬間(車が動き出すフレーム)の再生位置を確認する
2. ログで速度が 0 から立ち上がる時刻を確認する
3. `--sync` = (ログの発進時刻) − (動画の発進位置) を指定する
4. `--preview` や短い `--duration` で試し、ずれを `--offset` で詰める

## ログフォーマット

UTF-8(BOM 付き可)の CSV。列名はスクリプト冒頭の `COL` 辞書で内部キーに対応付けており、現行フォーマット(10 Hz、LOG0650 以降)と旧フォーマット(1 Hz、LOG0612 など)のどちらも読める。標高・気圧・気温・湿度・燃圧の列は無くてもよく(2025 年のログなど)、その表示は自動で省かれる。

| 列名(現行 / 旧) | 単位・内容 | 用途 |
| --- | --- | --- |
| 記録日時 | `YYYY/M/D HH:MM:SS.ff` | 時間軸 |
| 速度(km/h) | km/h | 速度ゲージ・グラフ |
| ラップ数(周目) / ラップ数 | 整数(スタート前は 0) | ラップ表示・ラップタイム |
| 走行時間(秒) / 走行時間 | 秒 | 走行時間表示 |
| 回転数(rpm) / 回転数 | rpm(0 = エンジン停止) | 回転ゲージ・ENGINE ON 判定 |
| 走行距離積算(m) / 走行距離 | m | 距離表示 |
| 積算燃料消費量(ml) / 積算燃料 | ml | 燃料表示 |
| 燃費(km/l) / 燃費 | km/L | 燃費表示 |
| lat(緯度) / lat、lng(経度) / lon | 度(未測位時は 0) | コース図・方位 |
| 標高(m) / alt | m | 標高グラフ(列が無ければ非表示) |
| 温度(C) / 温度 | ℃(エンジン温度) | 環境表示 |
| 気圧(kPa) / 気温(C) / 湿度(%) | — | 環境表示(列が無い項目は省く) |
| 燃圧(MPa) | MPa(現行のみ) | 燃圧グラフ(列が無ければ非表示) |

次の列は読み込むが表示しない: 燃料噴射時間(ms)、点火進角角度(CA)、燃料噴射終了角度(CA)、場所 / loc、1次空気圧(MPa)、2次空気圧(MPa)。

## レイアウトプリセット

見た目の設定はすべて `presets/*.toml` にある。コードを触らずに切り替え・編集できる。

| プリセット | 内容 |
| --- | --- |
| `default` | 標準。VSYSTO F9 ローアングル前方カメラ向け |
| `f9_mask` | `default` + 右下の焼き込み表示(日時・速度)を帯で隠し、帯の中に距離・燃料を出す(旧 `--mask-osd`) |
| `minimal` | 速度・回転・燃費・コース図・走行時間だけを小さめに四隅へ置く例 |

```toml
#:schema ../schema/preset.schema.json
schema_version = 1
name = "標準"

[theme]                 # 配色(#RRGGBB / #RRGGBBAA)とフォント
accent = "#FF8C00"

[data]                  # 判定の閾値
rpm_on_threshold = 300.0

[[keepout]]             # 配置禁止帯(lint が重なりを警告)
name = "地平線"
x = 0
y = 380
w = 1920
h = 260

[[widgets]]             # 配列の順番 = 重なり順(後ろほど前面)
id = "speed_gauge"
type = "speed_gauge"
enabled = true
x = 380                 # 座標は 1920x1080 基準の px。出力時に動画解像度へスケール
y = 700
w = 360
h = 360
max = 60
step = 10
```

- ウィジェットの種類: `timer`(走行時間・ラップ)、`speed_graph`、`heading`(方位)、`env`(温度・気圧など)、`map`(コース図)、`fuel_eco`(燃費)、`odometer`(距離・燃料)、`speed_gauge`、`rpm_gauge`、`alt_graph`(標高)、`fuel_p_graph`(燃圧)、`mask`(焼き込み表示を隠す帯)、`text`(任意テキスト)
- 文字サイズや余白は型ごとの基準サイズに対する比 `min(w / 基準幅, h / 基準高さ)` で拡縮する。ゲージは box に内接する円
- 各ウィジェットのパラメータ・既定値・範囲は `uv run ecorun-layout widgets` で一覧できる
- 未知のキーや範囲外の値はエラーになる(タイポ検出のため)

### GUI エディタ

```bash
uv run ecorun-gui          # http://127.0.0.1:8765 をブラウザで開く
```

- 中央のキャンバスでウィジェットをドラッグして移動、四隅・辺のハンドルでリサイズ(ゲージは正方形を保つ。Shift で縦横比固定)。矢印キーで 1 px、Shift+矢印で 10 px
- 右のパネルで選んだウィジェットのパラメータ、「全体設定」で配色・閾値・配置禁止帯を編集
- 下のタイムラインでログの時刻を動かして確認できる。動画を指定すると、そのフレームを背景に表示し `--sync` / `--offset` の同期合わせにも使える
- 「OCR で自動同期」ボタンで `--sync auto` と同じ自動同期をする(動画とログの指定が必要)。区間が複数あるときはタイムラインに「区間 2/3」のように出る。同期欄を手で書き換えると自動同期をやめる
- 動画欄は 1 行に 1 つ。複数行やフォルダを書くと連結して扱い、タイムラインは連結後の通し秒、横に今どのファイルの何秒目かを表示する
- 「開始」「終了」は `--start` / `--end`。「現在位置」ボタンでタイムラインの位置をそのまま入れられる。画面下のコマンドにも反映される
- 保存すると TOML のコメントや並びは保ったまま値だけ書き換える。別名で保存すると新しいプリセットになる
- 元に戻す / やり直す: ⌘/Ctrl+Z、⌘/Ctrl+Shift+Z。保存: ⌘/Ctrl+S
- TOML をテキストエディタや AI エージェントが書き換えると、GUI が自動で読み込み直す(編集中ならバナーで確認)
- 「書き出し」ボタンで、その場で書き出せる(サーバーが `ecorun-overlay` を別プロセスで実行。進捗バーと残り時間を表示し、「中止」で止められる)。画面のレイアウトは未保存の変更も含めてそのまま使い、OCR 済みの同期もやり直さない。出力先を空にすると動画と同じフォルダに `名前_overlay.mp4`(動画なしなら CSV の隣に透過 `.mov`)。複数の動画を読み込んでいれば「連結のみ」も出る
- 同じ処理のコマンド(プレビュー・合成・透過)も画面下に表示される。ターミナルで実行するときはコピーして使う
- API の一覧は <http://127.0.0.1:8765/docs>

### ecorun-layout(検証ツール)

```bash
uv run ecorun-layout list                 # プリセット一覧
uv run ecorun-layout widgets [TYPE]       # ウィジェットの種類とパラメータ
uv run ecorun-layout validate default     # スキーマ検証(未知キー・型・範囲・id 重複)
uv run ecorun-layout lint default         # キャンバス外・配置禁止帯・重なりの検査
uv run ecorun-layout schema --write       # schema/preset.schema.json を更新(config.py を変えたら)
```

いずれも `--json` で機械可読な出力になる。  
終了コードは問題なしで 0、エラーで 1(`lint --strict` は warning でも 1)。

### ログの列名

CSV の列名と内部キーの対応は `ecorun/telemetry.py` の `COL`(候補を複数書ける)と `OPTIONAL_COLS`(無くてもよい列)で定義している。

## 処理速度の目安

Apple Silicon Mac で毎秒約 50 フレーム(ProRes エンコード込み)、クラウド環境で約 13 フレーム。

## 開発

```bash
uv run pytest              # テスト(合成ログを使うので CSV は不要)
```
