# ecorun_overlay

Honda エコマイレッジチャレンジ用の車載動画テレメトリ・オーバーレイ生成ツール。
Chibi-T ロガーの CSV を読み込み、速度・回転数(エンジン ON / COAST)・燃費・ラップタイム・方位・コース図などを車載カメラ映像に重ねる。

![preview](docs/preview.png)

## 特徴

- **パルス&グライド向け表示**: 回転数から ENGINE ON / COAST を判定し、コース図と速度グラフ上でエンジン ON 区間をオレンジで表示
- **燃費・積算燃料・走行距離**: 距離が短い間の不安定な燃費値は `---` で非表示
- **ラップタイム**: `ラップ数` 列の切り替わりから現在周・前周タイムを算出
- **方位**: GPS 座標の移動ベクトルから算出(低速時は直前値を保持)
- **滑らかな補間**: 約 1 Hz のログを動画フレームレートへ線形補間
- **ドラレコ焼き込み表示のマスク**: VSYSTO F9 の日時・速度表示を `--mask-osd` で隠す
- **3 つの出力モード**: 静止画プレビュー / 動画へ直接合成 / 透過 ProRes 4444(編集ソフトで重ねる用)

## 必要なもの

- Python 3.9 以上
- ffmpeg / ffprobe(PATH が通っていること)
- 日本語フォント(Windows・macOS・Linux の標準的なものは自動検出。見つからない場合は `--font` で指定)

```bash
pip install -r requirements.txt
```

## 使い方

### 1. 静止画でレイアウトを確認

```bash
python ecorun_overlay.py LOG0612.CSV --preview 900 -o preview.png
```

`--preview` はログ開始からの秒数。グレー背景に 1 フレーム描画する。

### 2. 車載動画に直接合成

```bash
python ecorun_overlay.py LOG0612.CSV --video F9_0001.mp4 --sync 11:16:50 --mask-osd -o out.mp4
```

- 出力は H.264(`--crf` で画質指定、既定 18)。音声はコピーされる
- オーバーレイは 1920×1080 基準で描画し、動画の解像度へ自動スケール
- フレームレートと長さは動画から自動取得

### 3. 透過オーバーレイだけを書き出す

```bash
python ecorun_overlay.py LOG0612.CSV --sync 11:16:50 --duration 1300 -o overlay.mov
```

ProRes 4444(アルファ付き)を出力する。DaVinci Resolve や Premiere で映像の上に重ねて使う。

### オプション一覧

| オプション | 説明 |
|---|---|
| `csv` | ロガーの CSV ファイル |
| `-o`, `--output` | 出力先。`.png`(プレビュー)/ `.mp4`(合成)/ `.mov`(透過) |
| `--video` | 合成する車載動画 |
| `--sync` | 動画の 0 秒目に対応するログ時刻(`HH:MM:SS[.f]`)、またはログ開始からの秒 |
| `--offset` | 同期の微調整 [秒]。正の値で表示が先に進む |
| `--duration` | 出力する長さ [秒]。省略時は動画長、またはログ末尾まで |
| `--preview` | ログ開始からの秒を指定して静止画 1 枚を出力 |
| `--fps` | 透過出力時のフレームレート(既定 30。`--video` 指定時は動画に合わせる) |
| `--font` | 日本語フォント(`.ttf` / `.ttc`)のパス |
| `--crf` | H.264 の画質(既定 18、小さいほど高画質) |
| `--mask-osd` | ドラレコの焼き込み日時・速度を帯で隠し、そこに距離・燃料を表示 |

## 動画とログの同期

1. 動画で発進の瞬間(車が動き出すフレーム)の再生位置を確認する
2. ログで速度が 0 から立ち上がる時刻を確認する
3. `--sync` = (ログの発進時刻) − (動画の発進位置) を指定する
4. `--preview` や短い `--duration` で試し、ずれを `--offset` で詰める

> VSYSTO F9 の焼き込み時刻は、カメラの時計が正しく設定されていないとログと一致しない。焼き込み時刻をそのまま `--sync` に使う前に、日付が合っているか確認すること。

## ログフォーマット

UTF-8(BOM 付き可)の CSV。列名はスクリプト冒頭の `COL` 辞書で対応付けている。

| 列名 | 単位・内容 | 用途 |
|---|---|---|
| 記録日時 | `YYYY/M/D HH:MM:SS.ff` | 時間軸 |
| 速度(km/h) | km/h | 速度ゲージ・グラフ |
| ラップ数 | 整数(スタート前は 0) | ラップ表示・ラップタイム |
| 走行時間 | 秒 | 走行時間表示 |
| 回転数 | rpm(0 = エンジン停止) | 回転ゲージ・ENGINE ON 判定 |
| 走行距離 | m | 距離表示 |
| 積算燃料 | cc | 燃料表示 |
| 燃費 | km/L | 燃費表示 |
| lat / lon | 度(未測位時は 0) | コース図・方位 |
| alt | m | (未使用) |
| loc | 文字列 | (未使用) |
| 温度 | ℃(エンジン温度) | 環境表示 |
| 気圧(kPa) / 気温(C) / 湿度(%) | — | 環境表示 |

## カスタマイズ

スクリプト冒頭の「テンプレート設定」で変更できる。

| 設定 | 内容 |
|---|---|
| `ACCENT`, `SPEED_COL`, `PANEL` など | 配色 |
| `SPEED_MAX`, `RPM_MAX` | ゲージの上限 |
| `RPM_ON_THRESHOLD` | ENGINE ON とみなす回転数 |
| `FUEL_ECO_MIN_DIST_M` | 燃費を表示し始める距離 |
| `LAP_TOTAL` | 総周回数(`LAP 2/3` 表示にする場合) |
| `OSD_MASK_BOX` | ドラレコ焼き込み表示を隠す領域(1920×1080 基準) |
| `COL` | CSV の列名の対応 |

パネルやゲージの位置は `OverlayRenderer.__init__` のレイアウト定義で変更する。

## 処理速度の目安

クラウド環境で毎秒約 13 フレーム(エンコード込み)。20 分の動画で 30 分前後。
デスクトップ PC ではこれより速くなる。
